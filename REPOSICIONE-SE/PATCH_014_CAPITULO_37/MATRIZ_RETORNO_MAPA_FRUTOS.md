# MATRIZ DE RETORNO — MAPA DOS FRUTOS

## Modelo sem pontuação

| Galho | Registro inicial | Observação atual | Condições comparáveis? | Resultado | Evidência | Fatores externos | Recurso | Próximo movimento |
|---|---|---|---|---|---|---|---|---|
|  |  |  | Sim / Parcialmente / Não | Mudou / Permaneceu / Ainda não sei / Não comparável |  |  |  |  |

## Definições

| Resultado | Uso correto | Uso incorreto |
|---|---|---|
| Mudou | diferença observável e situada | transformação total |
| Permaneceu | fruto semelhante no período | fracasso pessoal |
| Ainda não sei | evidência insuficiente ou contraditória | resposta proibida |
| Não comparável | condições mudaram substancialmente | evitar qualquer observação |

## Salvaguardas

- Escolher de três a cinco Galhos.
- Não preencher por obrigação.
- Não usar notas.
- Não somar resultados.
- Não comparar com outra pessoa.
- Não atribuir causalidade automática.
- Registrar fatores externos.
- Preservar o que funciona.
- Aceitar privacidade.
- Definir data de revisão quando útil.
